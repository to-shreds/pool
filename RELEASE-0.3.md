# Cue Lab 0.3.0: implemented release and remaining scope

## Implemented

Searchable, no-scroll Settings with 68 operational fields across 12 categories; draft/apply/cancel; persisted settings and actual old-save migration. Arcade/Simulation/Custom; exact or skill-varied human delivery; same execution module for computers; exact finite-model risk indicator; real chalk/friction and shot-dependent condition state; deterministic undo/replay.

Actual per-ball radius/mass/inertia and world-specific 7/8/9/custom table geometry. Original 2D preserved. Real WebGL shooter/elevated/broadcast/auto cameras, look/orbit, field of view, height/distance, quality/shadows/lighting, immediate 2D fallback, overhead inset and unchanged precision-placement close-up. Cosmetic frame/felt/cue presets including original brand-inspired themes without logos.

Computer opponents and watch mode, skills 2-7, analysis/presentation controls, pause/resume. Shared off-thread simulated search and coach; strategic explanation from evaluated outcomes, alternative candidates, ideal landing zone, bounded skill-perturbation samples, non-mutating ghost demo, explicit apply without automatic shooting, per-rack timeout counts and non-punitive advice clock.

All original modes plus separate APA-derived 8/9 rules, official handicap chart data, point/rack races, sequential playable lag, breaker order, next-rack flow, defense/inning/stat records, supported frozen/off-table/head-string/break/8-loss rules, agreed stalemates, contact/referee review. Named practice drills, continued JSON portability, procedural audio and optional supported haptics.

## Not represented as complete

This release implements the major systems, but does not finish every ambitious item in the approved roadmap. Real-table calibration, empirically matching SL2-7 playing strength, deep multi-ball pattern search and high-level safety/bank accuracy remain unfinished. Skill/risk/chalk values are explicit simulation models, not measured APA odds. Coach search is bounded, not globally optimal.

No exact licensed manufacturer 3D models, online multiplayer, team league administration, full official score-sheet submission, official skill calculation, ghost-rack challenge competition, full room/environment art, unlimited free-camera replay editing, specialty cue inventory, complete shaft obstruction/double-hit referee or fully modeled hanging/rattle-back pockets. Remaining rule exceptions stay documented. Features without working implementations are not offered as fake functioning settings.

Physical Android performance, native GPU behavior across devices, ordinary local-file opening under an unrestricted browser, native persistence across browser restarts and a public Pages URL still require their own verification. The current build environment's restrictions and test coverage are stated in the verification report.

## Preservation

The verified 0.2 code remains recoverable on the baseline branch and in earlier release attachments. Existing Club rules are separate from APA modes. Original saves receive backward-compatible defaults. Any future implementation must preserve no-scroll usability, copied-world coaching, exact state restoration and camera/physics independence.
